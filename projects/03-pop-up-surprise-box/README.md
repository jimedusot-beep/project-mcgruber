# Pop-Up Surprise Box

**Goal:** Release a lightweight figure from a box when opened or triggered.

**Status:** Mechanical approach proposed, not tested.

## Required hardware or software (proposed)
Cardboard box, hinged lid, folded-paper spring or safe low-force spring, latch, lightweight figure, adhesive; optional actuator and detector.

## Next verification
First confirm repeatable low-force mechanical release; then test actuator linkage.
