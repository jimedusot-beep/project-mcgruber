# Object-Removal Alarm

**Goal:** Sound or display an alert when an object is lifted.

**Status:** Mouse microswitches reportedly salvaged; individual contacts untested.

## Required hardware or software (proposed)
Tested NO/NC switch, load/platform, power supply, LED with resistor or rated active buzzer, optional driver.

## Next verification
Measure continuity with switch unpowered; document normally-open/closed states and ratings.
