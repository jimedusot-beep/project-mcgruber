Reusable circuits

Visible emitter — 9V + LED (conditional)

9V (+) → measured 1 kΩ series resistor → LED anode → LED cathode → 9V (−)

Power off while connecting. Measure resistor voltage and use I = V_R / R. If no resistor is found, do not energize the LED. Never assume the bare NightFire PCB limits current.

2N4401 manual switch test (not optical yet)

9V+ → 1 kΩ → indicator LED → NPN collector; NPN emitter → 9V−; 9V+ → momentary 10 kΩ → NPN base

Optional verified 100 kΩ base-to-emitter pull-down. LED should turn ON only with the controlled base touch. Verify your exact E/B/C pins. A manufacturer's 2N4401 may assign opposite collector/emitter lead order to another supplier's 2N4401.

Actual sensor circuit — design still missing

Light receiver → suitable amplifier / current-to-voltage conversion → comparator + hysteresis → NPN indicator driver

A few mV from an unpowered LED on your meter cannot be connected directly to a 2N4401 base and expected to trigger. Real circuit parameters require actual sensor characterization and identified amplifier/comparator components.

Object-removal alarm — mouse switch

Disconnect all power and find COM/NO/NC using continuity in pressed and released positions. Only afterward choose the contact pair so removing the object closes the LED circuit with correct series resistor and battery. Test 20 cycles.

Invisible IR route — future

Requires a known IR emitter and matching receiver, correct drive/modulation and documented output. A TV remote transmits coded bursts and is not an autonomous continuous beam by itself.
