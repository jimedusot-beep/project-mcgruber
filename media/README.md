# Authentic demonstration media

The project welcomes real build photographs, calibration screenshots, wiring photographs and demonstration videos. **None have been supplied for publication as part of this package.** Generated diagrams and CAD previews are not physical evidence.

See [media manifest](manifest.csv) for all nine expected project evidence entries and [capture checklist](CAPTURE_GUIDE.md). Open-source contributions should avoid faces, home/vehicle addresses, visible serial numbers and private information. Only upload files the uploader owns or has rights to distribute.

Place actual authorized media in `media/photos/` and `media/videos/` as small optimized files; prefer GitHub release assets or a proper media host for large video files and link the immutable evidence into each project test log. Do not fabricate or edit an image in a way that would imply a test occurred.
