# Optional Arduino test fixture for McGruber P04/P06

See [first build track](../../docs/FIRST_SWITCH_BUILD_TRACK.md) for the unpowered measurement gates, exact COM/NC wiring, 20-cycle test, and distinction between a direct 9V switch+LED circuit (no Arduino needed) and this optional programmable alternative.

Requires a compatible board, verified isolated switch, Arduino IDE and the [MIT-licensed Bounce2 library](https://github.com/thomasfredericks/Bounce2) through Library Manager. The repo contains only an original example sketch; no Bounce2 code is vendored. **Firmware compilation and physical hardware operation are not yet verified.**
